**新手必知**：Node.js 不是"给后端用的"。它是把 JS 引擎（V8）搬出浏览器，让你能在命令行里跑 JS。
Astro 的「构建」就是把你的 `.astro`/`.md` 源码在 Node 里跑一遍，产出静态 HTML。
**所以构建阶段能跑 Node API（读文件、fetch API），但这些代码不会进浏览器。**

      —— 看到变化后**刷新页面，改动会消失**。这说明 F12 改的是内存里的 DOM，不是文件
- [ ] 说得出 HTML / CSS / JS 三者各自负责什么（结构 / 样式 / 行为）
- [ ] 理解 DOM 是什么：浏览器把 HTML 文本解析成内存里的一棵树

**核心心智模型**：没有 `main()`。浏览器加载 HTML → 解析成 DOM → 执行 `<script>` → 布局 → 绘制。
之后一切由**事件**驱动（点击、滚动、定时器），由**事件循环**排队执行。

## 阶段 6 · GitHub 关联

- [ ] 先让 SSH 认识 github.com：`ssh -T git@github.com`（第一次问 `yes/no` 输 `yes`）
      —— 不然 `git` 会报 `Host key verification failed`，**那跟密钥和网络都无关**
- [ ] 生成 SSH 密钥：`ssh-keygen -t ed25519 -C "你的邮箱"`，把公钥贴到 GitHub → Settings → SSH keys
- [ ] 验证通道：`ssh -T git@github.com` 应显示 `Hi 你的用户名!`
      —— 若显示 `Permission denied (publickey)`，说明通道是通的，只是密钥还没被识别
- [ ] `.gitignore` —— **已建好**（`node_modules/`、`dist/`、`.env` 等）
- [ ] `git remote add origin git@github.com:用户名/仓库名.git` ← ⚠️ **必须 SSH，HTTPS 被阻断**
- [ ] 用 Netlify 的 Git 集成或 GitHub Actions 实现"push 即部署"
- [ ] README 写清楚怎么本地跑起来
