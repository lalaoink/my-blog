> **用途**：阶段 3 你要自己写 CSS 时，这里给你一个精确的参照系。
> **注意**：数值可以直接用，但这套配色是你朋友的——最后建议换成你自己的。

| 项 | 实际用的 | 证据 |

## 二、设计令牌（`<style is:global>` 里的 `:root`）

```css
:root {
  /* 中性色 */
  --gray:            #6a6d6e;
  --dark-gray:       #444;      /* 正文文字色 */
  --very-dark-gray:  #222;      /* 标题、强调文字色 */

  /* 海蓝系（主色） */
  --very-light-sea-blue: #8dbeff;
  --light-sea-blue:      #59a6ff;
  --sea-blue:            #316fd3;   /* 链接色 */
  --dark-sea-blue:       #2655b9;

  /* 沙黄系（强调色） */
  --sand-yellow:       #f3ec86;
  --light-sand-yellow: #fff9c5;
}
```

**配色逻辑**：只有三个色相 —— 中性灰（文字）、海蓝（主色/链接）、沙黄（强调）。
而且 `--dark-gray #444` 是**正文**色而不是纯黑，`--very-dark-gray #222` 才是标题色。
**这是一个很值得偷的技巧**：正文用 `#444` 比 `#000` 柔和得多，长时间阅读不刺眼。

## 三、编排与排版（极简风的真正来源）

```css
body {
  margin: auto;            /* 居中 */
  padding: 20px;
  max-width: 65ch;         /* ★ 核心 */
  line-height: 1.5;
  word-wrap: break-word;
  font-family: var(--mono-basic);
}

main  { min-height: 90vh; }                 /* 把页脚顶到视口底部 */
footer{ margin-top: 70px; margin-bottom: 50px; opacity: .9; text-align: center; }
header{ margin: 0 0 1.6em; }
```

### ★ `max-width: 65ch` —— 这一行就是"极简排版"的全部秘密

`ch` 是**当前字体下字符 "0" 的宽度**。`65ch` 意味着"每行大约 65 个字符宽"。

为什么这比 `max-width: 700px` 高明？
- 排版学上，一行 **45~75 字符**是阅读舒适区。用 `ch` 就**直接锁定了这个生理约束**，而不是猜一个像素值。
- 用户放大字体时，`px` 容器不变、每行字符变少（可能只剩 20 个，很难读）；`ch` 容器会**跟着一起变宽**，始终维持 65 字符。
- 这就是**响应式排版**的第一课，而且完全不依赖媒体查询。

**你要学的东西**：写 `max-width` 时先问自己"我希望一行放多少字？"

### 字体栈

```css
--mono-basic: "PingFang SC", "Hiragino Sans GB", "Microsoft YaHei", "WenQuanYi Micro Hei", sans-serif;
--mono-more:  Verdana, var(--mono-basic);
```

注意名字带 `mono`（等宽）但实际是**无衬线中文字体栈**，命名有误导性。它是"按操作系统逐个回退"的典型写法：
macOS 命中 PingFang → Windows 命中 Microsoft YaHei → Linux 命中 WenQuanYi。

### 其它排版细节

| 规则 | 作用 |
| --- | --- |
| `body { line-height: 1.5 }` / `content { line-height: 1.6 }` | 正文 1.5，长文 1.6（更大的行距更适合通读） |
| `a { text-decoration: none }` + `a:hover { text-decoration: underline }` | 平时干净，悬停才提示可点 —— 比一直带下划线优雅 |
| `time { font-style: italic }` | 日期用斜体做弱化 |
| `blockquote { font-style: italic; font-size: .98em; border-left-width: 2px; padding: 1px 0 1px 10px; margin: 0 }` | **只用左侧一条 2px 竖线**，不加背景不加四边框 |
| `textarea, input { font-size: 16px }` | ★ **移动端关键**：iOS Safari 上输入框字号 < 16px 会触发"聚焦自动放大页面" |
| `table { width: 100% }` | 表格撑满 |

### 盒模型细节

```css
input { border: 2px solid var(--very-dark-gray); border-radius: 7px; margin: 5px 5px 5px 0; padding: 5px 5px 5px 8px; }
input:focus { outline: 0px; }
```

**注意**：边框统一用 `2px`（不是 1px）。`2px` 是这个站的视觉签名之一——比 1px 更"实"、更有个性。

## 四、那个标志性的斜条纹导航条

```css
nav {
  background-image: linear-gradient(135deg,
    var(--dark-sea-blue)     0%,
    var(--sea-blue)         38%,
    var(--sea-blue)         52%,
    var(--light-sea-blue)   52%,   /* ← 52% 出现两次 = 硬边界 */
    var(--light-sea-blue)   58%,
    var(--very-light-sea-blue) 68%,
    var(--sand-yellow)      68%,   /* ← 68% 出现两次 = 硬边界 */
    var(--sand-yellow)     100%);
  background-size: 110% 200%;
  color: #fff;
  border-radius: 8px;
  transition: all .18s cubic-bezier(.45,.05,.55,.95);
}
nav a { display: inline-block; margin: 5px 3px; font-size: 21px; font-weight: 700; }
```

**技法要点**：同一条 `linear-gradient` 里，**同一个百分比写两次**（`52%` 出现两遍）就会产生**硬边界**而不是平滑过渡。这是用 CSS 画"色块拼接"的标准手法。

`45deg` 斜向 + 三个蓝色 + 一个黄色，就做出了"海面与沙滩"的意象。

**配套的鼠标跟随**（在首页的 `<script>` 里）：

```js
nav.addEventListener('mousemove', e => {
  const rect = nav.getBoundingClientRect();
  let shift = e.clientX - rect.left - 600;
  shift = Math.min(Math.max(shift * 0.2, -50), 0);   // 阻尼 + 夹取范围
  nav.style.backgroundPosition = `${shift}px 0px`;
});
```

鼠标在导航条上移动时，渐变背景会**平移一点点**——因为 `background-size: 110%` 留了 10% 余量，所以平移不会露白。这就是"视差感"的来源，代价只有三行 JS。

## 五、入场动画（可以直接抄思路）

```css
@keyframes slide-enter {
  0%  { opacity: 0; transform: translateY(25px); }
  to  { opacity: 1; transform: none; }
}

.slide-enter-content > * {
  --delay: .2s;
  --start: 0ms;
  animation: slide-enter .6s both 1;
  animation-delay: calc(var(--start) + var(--stagger) * var(--delay));
}

.slide-enter-content > *:nth-child(1) { --stagger: 1 }
.slide-enter-content > *:nth-child(2) { --stagger: 2 }
/* ...一直写到 nth-child(20)... */
```

**思路拆解**：给容器里每个直接子元素循环赋一个递增的 `--stagger`，再用 `animation-delay` 乘上 `--delay`，就得到"逐条错位淡入上浮"的效果。

`both` 这个 `animation-fill-mode` 值很关键：让元素在动画开始前就保持 `0%` 的状态（透明），避免"先闪现再消失再淡入"。

⚠️ **代价**：它手写了 20 条 `nth-child`。这是"能用但不够优雅"的典型——你可以用 CSS 预处理器循环，或者干脆用 JS 生成。

## 六、其它小工具类

```css
.pushable {                    /* 所有可点元素都挂了这个 */
  user-select: none;           /* 防止双击选中文字 */
  -webkit-tap-highlight-color: transparent;  /* 去掉移动端点击的蓝色高亮方块 */
}

@keyframes throttle { 0% { pointer-events: none } to { pointer-events: all } }
.throttle { animation: throttle .3s step-end forwards }
.throttle:active { animation: none }
```

`.throttle` 是个**纯 CSS 节流**技巧：元素在加载后的 0.3 秒内 `pointer-events: none`（收不到点击），用 `step-end` 让状态在动画结束时才跳变。目的是防止页面刚好看就被误点。

## 七、给你的实操建议

**不要整段复制这套 CSS。** 理由有两个：一是这是你朋友的成果，二是抄下来你学不到东西。建议按这个顺序做：

1. **先只用它的一半**：抄 `:root` 变量 + `body { max-width: 65ch }` + 字体栈。这三样就能让一个丑页面立刻有"版式感"。
2. **写你自己的页面，看看哪里别扭**——你会开始主动需要 `line-height`、`margin` 控制。
3. **最后再回来看这份文档**，那时你会觉得每一条都"理所当然"。

**唯一建议你原样保留的**：`textarea, input { font-size: 16px }`。这不是审美问题，是移动端可用性问题。
