发布

「直接发布」做了什么？
它用你的登录凭证，把转换结果直接写进 GitHub 仓库的 src/content/blog/，然后 Netlify 会自动重新构建 —— 大约一分钟后文章就上线了。不需要复制粘贴，也不需要碰 git。

如果没登录 / 发布失败，可以用「复制 Markdown」走老流程： 打开 内容管理 → + 文章 → 粘贴进正文。
