## 基本格式

```markdown
# 一级标题（一篇文章里只用一个）
## 二级标题（会自动进目录）
### 三级标题

**粗体**    *斜体*    `行内代码`
~~删除线~~

[链接文字](https://example.com)
![图片说明](/images/foo.png)
```

渲染出来是这样：**粗体**、*斜体*、`行内代码`、~~删除线~~。

## 代码块

用三个反引号包起来，**在开头写上语言名**，就会有语法高亮：

````markdown
```cpp
int main() {
    return 0;
}
```
````

效果：

```cpp
#include <iostream>

int main() {
    // 有高亮，因为标了 cpp
    std::cout << "hello" << std::endl;
    return 0;
}
```

## 文章开头的 frontmatter

每篇文章**必须**以这段开头，两边的 `---` 不能少：

```markdown
---
title: 文章标题
date: 2026-09-23
description: 一句话摘要，会显示在列表页
tags: ["标签一", "标签二"]
draft: false
---
```

- `title` 和 `date` 是**必填**，漏了构建会直接报错并告诉你是哪个文件。
- `draft: true` 的文章不会发布，方便存草稿。

## 几个容易踩的坑

1. **标题后面要有空格**：`## 标题` 对，`##标题` 错。
2. **中英文之间加空格**读起来舒服，但不是语法要求。
3. **代码块的语言名别乱写**，写错了只是不高亮，不会报错。
4. **空行分隔段落**，单个换行在 Markdown 里等于没换行。
